# Skill: Diff Review (`diff_review`)

Ejecutar `git diff --check`, revisar status, stat y diff completo (también
staged cuando aplique). Buscar secretos, imports innecesarios, duplicación,
regresiones, dependencias superfluas y contratos/configuraciones hardcodeados.
Comprobar componentes mantenibles, alcance, documentación y validación.
En tareas de fábrica, confirmar que no se implementó Vue/Grafana accidentalmente.
Salida: review con hallazgos o evidencia de ausencia; resolver antes de DONE.
