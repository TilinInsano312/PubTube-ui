# Skill: Final Reporting (`reporting`)

Reportar DONE, PARTIAL o BLOCKED, rama/base, resumen, cambios, AC y evidencia,
validaciones, conteos de tests, Git/PR, review, riesgos y pendientes.
No declarar PASS ni DONE sin evidencia. Usar NOT VERIFIED cuando corresponda.
No incluir secretos ni logs completos. Indicar merges pendientes de autorización.
Ver [plantilla](../templates/agent-report-template.md).
