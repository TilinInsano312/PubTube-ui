# Tarea breve para Codex

```text
Tarea:
[Qué debe cambiar o resolverse.]

Resultado esperado:
[Cómo debe quedar el repositorio o la experiencia.]

Criterios de aceptación:
- [Resultado observable 1.]
- [Validación o resultado observable 2.]
```

Instrucción sugerida:

> Ejecuta esta tarea siguiendo la fábrica agéntica del repositorio. Lee
> `AGENTS.md` antes de editar.

Codex debe inspeccionar el repositorio, convertir la solicitud en un contrato
operativo con scope y validaciones, implementar solo lo autorizado y reportar
`DONE`, `PARTIAL` o `BLOCKED` con evidencia. Para tareas versionadas con orden y
dependencias se usa el [formato JSONL](../../tasks/README.md).
